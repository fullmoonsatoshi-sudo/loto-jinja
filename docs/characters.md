# キャラクター設定書

- 作成：designer（2026-11-26）
- 方針：かわいく、やさしい。参考アプリ（AI.inc「当選祈願」）の巫女とは、見た目も性格も役割も別物にする。実在のキャラクターやほかの作品に似せない。

## 共通ルール
- 画風：やわらかい線のデフォルメ（2〜2.5頭身）、パステル調、太めの輪郭線、影は1段だけ
- 背景：透過PNG（アプリ側で背景を描くため）
- サイズ：1024×1024。全身が中央におさまり、上下に余白を残す
- 表情は4種：
  - normal（通常・にっこり）
  - pray（手を合わせてお祈り。目を閉じ、まわりに小さな光の粒）
  - joy（当たった！両手を上げて大喜び）
  - sad（外れた…しょんぼり、汗マーク）
- 3キャラは同じ画風・同じ縮尺でそろえる

## 1. 見習い巫女「かなえ」（基本キャラ）
- 設定：さびれた小さな神社の見習い巫女。みんなの願いを叶えて神社を立て直すのが夢。ちょっとドジだが一生懸命
- 見た目：明るい茶色のボブヘア、大きな赤いリボン（白い水引の飾り付き）、白衣と**赤い袴（緋袴）**（巫女の伝統的な装束。参考アプリとの差は、リボン・鈴・性格・設定でつける）、手に**神楽鈴（かぐらすず）**（木の持ち手の先に、小さな金色の鈴が三段に付いた鉾先鈴。持ち手の端から五色の布（緑・黄・赤・白・紫）が長くたなびく）
- 口ぐせ：「かなえにおまかせください！」「むむむ…神託がおりてきました！」
- テーマカラー：赤 ＋ 金

## 1b. 見習い神主「あたる」（男の子・かなえの相棒）
- 設定：同じ神社で修行中の見習い神主。かなえの幼なじみで、落ち着いたしっかり者。名前は「当たる」から。かなえ（願いを叶える）とあたる（くじが当たる）でコンビ
- 見た目：黒髪の短髪（前髪は少し長め）、白い着物（白衣）に**浅葱色（あさぎいろ）の袴**。浅葱色は、ごく薄い緑がかった水色で、若い神職の袴として伝統的に使われる色。手に紙垂（しで）の付いた大幣（おおぬさ）を持つ
- 口ぐせ：「落ち着いて。神託はちゃんと届いてるから」
- テーマカラー：浅葱色 ＋ 白

## 2. 子ぎつねの神様見習い「こん」
- 設定：お稲荷さんの神様見習い。数字が大好きで、データ分析が得意
- 見た目：二足で立つクリーム色の子ぎつね、ふわふわのしっぽ、首に赤い前掛け、小さな巻物を持つ
- 口ぐせ：「こんこん、データによると…」
- テーマカラー：クリーム ＋ 朱色

## 3. 招き猫の巫女「ふく」
- 設定：福を呼ぶ招き猫が巫女修行中。運気担当で、ラッキーナンバーが得意
- 見た目：白い三毛猫（耳と背中に茶と黒のぶち）、首に金の鈴、巫女風の小さな羽織、片手を上げた招きポーズが基本
- 口ぐせ：「福をおまねきするにゃ！」
- テーマカラー：白 ＋ 桜色 ＋ 金
