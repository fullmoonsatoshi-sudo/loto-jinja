# オーナーにお願いすること（ロト神社を Google Play に出すまで）

ここまでで、アプリ本体・公開サイト・Android 用の署名済みファイル・ストア用の画像と文章は、すべて揃っています。
残りは、**オーナー本人にしかできない手続き**だけです。

## できあがっているもの（すべて外付けHDD内）
| もの | 場所 |
|---|---|
| 署名済みの Android アプリ（Play に上げるファイル） | `projects/loto-app/release/loto-jinja-1.0.0-1-signed.aab` |
| 署名の鍵とパスワード（**絶対に無くさない・人に渡さない**） | `secrets/` |
| ストア用の画像（アイコン・フィーチャーグラフィック・スクショ6枚） | `projects/loto-app/store/`、アイコンは `src/assets/icon-512.png` |
| 説明文・データセーフティ・レーティングの回答案 | `projects/loto-app/docs/store-listing.md` |
| プライバシーポリシー | https://fullmoonsatoshi-sudo.github.io/loto-jinja/privacy.html |

## オーナーの作業（順番どおり）
1. **Play Console のデベロッパー登録**
   - https://play.google.com/console で登録。登録料 25ドル、本人確認（身分証）があります。
   - 種類は「個人」で大丈夫です。住所・電話番号の確認がある場合があります。
   - 連絡先メールアドレスはストアに公開されます（公開してよいアドレスを使ってください）。
2. **アプリを作成**：アプリ名「当たれ！ロト神社 ロト6・ロト7当せん速報」、無料、アプリ（ゲームではない）。
3. **掲載情報の入力**：`store-listing.md` の文章と、`store/` の画像をそのまま使えます。
   - 「アプリのコンテンツ」の質問（データセーフティ・レーティング・対象年齢18歳以上・広告なし・アクセス権・ニュース/金融/健康/政府アプリか）も、同じファイルに回答案があります。
4. **クローズドテスト**（個人アカウントの必須ルール）
   - 「テスト → クローズドテスト」に `.aab` を上げ、**12人以上**のテスターに参加してもらい、**14日間続けて**参加状態を保つ必要があります。
   - 終わったら「製品版へのアクセスを申請」。審査は通常7日以内です。
   - テスターは Gmail アドレスでリストに追加し、テスト用リンクを送るだけです。
5. **Play アプリ署名の指紋を CEO（Claude）に教える**（最初の .aab を上げた直後、テスターを集める前に）
   - 「テストとリリース → アプリの完全性 → アプリ署名」に出る **「アプリ署名鍵の証明書」の SHA-256** をコピーして送ってください。
   - これを `assetlinks.json` に足すと、アプリ上部にアドレスバーが出なくなります（足すのは Claude がやります）。
6. **製品版として公開**。

## 公開前に一度だけ見てほしいこと
- 外付けHDDの `release/` に .aab、`secrets/` に鍵があること（鍵は別の場所にもバックアップを。無くすとアプリを更新できなくなります）。
- アプリの「ホーム」で最新回が公式発表と同じになっていること。

## 自動で動いているもの（オーナーの作業なし）
- 抽せん日の夜に当せん番号を自動で取り込み、サイトを更新（GitHub Actions）。
- 翌朝にキャリーオーバー額を公式CSVと照合して書き足し（Claude の定期タスク）。
- サイトが更新されると、インストール済みのアプリにもそのまま反映されます（アプリの作り直し不要）。

## アプリを作り直すとき（見た目や名前を変えるとき）
- `tools/android/app.json` の `versionCode` を1つ上げて、GitHub の「Androidアプリを作る」を実行 → Claude が署名して HDD に置きます。
