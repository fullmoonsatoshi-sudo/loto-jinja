# キャラクターのせりふ 仕様（2026-11-27 オーナー決定）

## 方針
- 状況ごとに、キャラ1人あたり **31個** ずつ用意する。
- 同じ状況なら、**日本時間の今日の日付（1〜31日）** で何番目のせりふを出すかを決める。1ヶ月のあいだ毎日ちがうせりふになる。
- ただし newyear だけは別の選び方（下の「newyear の出し方」）。
- キャラ4人（かなえ・あたる・こん・ふく）それぞれ別のせりふ。

画面を開いたままでも、5:00・11:00・12:00・17:00・18:45・0:00（年末年始は毎時0分）にホームのせりふが変わる。

### newyear の出し方
年末年始は4日間しかないので、日付だけで選ぶと4〜30番目が使われない。そこで日本時間の「時」で選ぶ。
- 各日の0時台：その日のあいさつ（12/31 は31番目、1/1 は1番目、1/2 は2番目、1/3 は3番目）
- 1時台〜23時台：4〜30番目（27個）を1時間ごとに順に出す。日ごとに前の日の続きから始めるので、4日間で27個すべてが出る
- そのため 4〜30番目は、12/31 にも 1/1〜1/3 にも出てよい内容にする（「あけましておめでとう」「よいお年を」など日の決まる言葉は 1〜3番目・31番目へ）

## せりふのルール（必ず守る）
1. **当たる確率が上がる・当たりやすくなる・運で結果が変わる、と受け取れることは言わない。** 「この番号は来る」「今日はツイてる」「ご祈祷したから当たる」「福を呼んだから大丈夫」などは禁止。ご祈祷・神託・運気は「お楽しみ」「気持ち」の話として言う。
2. **買うことをあおらない。** 「たくさん買おう」「今買わないと損」「キャリーオーバーだからチャンス」「一攫千金」は禁止。無理のない範囲・楽しめる範囲で、という姿勢。
3. **事実と違うことを言わない。** くじの事実：ロト6は月・木、ロト7は金、ミニロトは火、ビンゴ5は水、ナンバーズ3・4は月〜金、抽せんはどれも18:45（日本時間）。ロト6は1〜43から6個、ロト7は1〜37から7個、ミニロトは1〜31から5個、ビンゴ5は3×3の盤面（中央はFREE）で8つの数字、ナンバーズは3桁・4桁でストレート・ボックス・セット・ミニ（ミニはナンバーズ3だけ）。キャリーオーバーがあるのはロト6・ロト7だけ。年末年始（12/31〜1/3）は抽せんなし。当せん金の具体的な金額・確率の数字は書かない。このアプリで宝くじは買えない。
4. 20歳未満・未成年に向けた言い方、お酒・恋愛・お金の悩みにつけこむ言い方はしない。だれかを傷つける冗談、実在の人物・作品・商標の名前は出さない。
5. はずれのせりふで「次は当たる」と言わない。「残念」「また楽しもう」「無理しないで」など。
6. 当せんのせりふで「もっと買おう」と言わない。「公式で確認して受け取ってね」は良い。
7. 1つのせりふは全角40文字以内（cutin は16文字以内）。ふきだしに1〜2行で収まる長さ。
8. 同じキャラ・同じ状況の中で、ほぼ同じ文を繰り返さない（31個すべて中身がちがう）。

## キャラの話し方（docs/characters.md も読むこと）
- **かなえ**（見習い巫女・基本キャラ）：ていねいな「です・ます」。ちょっとドジで一生懸命、元気。神社を立て直すのが夢。口ぐせ「かなえにおまかせください！」。神楽鈴を持つ。
- **あたる**（見習い神主・かなえの幼なじみ）：落ち着いたしっかり者の男の子。親しみのある「だよ・だな・〜しよう」。かなえを見守る。大幣を持つ。
- **こん**（子ぎつねの神様見習い）：語尾「〜こん」。数字とデータが大好き（ただし「データで当たる」とは言わない。数字の並びや記録を眺めるのが好き、という言い方）。巻物を持つ。
- **ふく**（招き猫の巫女）：語尾「〜にゃ」。ほんわか、福を招くのが好き（ただし「福で当たる」とは言わない。みんなに笑顔の福を、という言い方）。首の金の鈴、小さな神楽鈴。
